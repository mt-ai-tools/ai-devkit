# stand-in

A stand-in for the operator over the questions an agent puts to them,
judging each against the project's written rules and conventions and a
preset of the operator's own judgement, in the sessions it is switched
on for.

It is switched on for a session by a command the operator types, and in
no other way; where it is off it does nothing, and asks no model.

Models read; code decides. Nothing is ever decided from a model's words,
only from a form a check in code has passed, and a form that fails is
refused, never repaired or guessed at. It reads the reply it is handed
and never a conversation itself. It knows no kind of question, no risk,
no rule and no convention by name: whatever the preset and the two
collections hold is what it judges by.

It fails toward the operator: whatever it cannot read or judge lets the
reply stop with the reason shown to them, and it never holds one
question past a small number of send-backs. A recommendation that puts
work off, and a request to start building, always reach the operator,
and it never changes how a kind of question is routed. A settling or a
go that cannot be logged is never given.

A wait on another session's work reads that work and never takes,
commits or pushes it. No test case it writes holds the raw text of its
log, or anything either of its secret checks finds. Its exam is never
part of the everyday test command.

Needs a preset of the operator's judgement: the kinds of question and
how each is routed, the risks, and the words it challenges, sweeps and
opens a session with. Needs the rules, and the conventions where a
project keeps them, and the kit's advisor, for a second reading. Needs a
working folder of its own, part of which a project commits. Needs the
kit's work organizer, for the briefs a session takes, waits on and
finishes. Needs Claude Code to set the session's id in the environment
of the commands its agent runs, and to wake a session when a background
command it started finishes; each of its hooks registered for the
Claude Code event the hook's own header names, the gate with a time
limit no shorter than the one it declares; and its skills offered to
the agent. Needs the Claude Code command-line tool, signed in, to ask
models through; the tool installer `mise`, called for one command at a
time and never activated, with the Betterleaks secret scanner installed
through it at the release the stand-in pins, which it never fetches by
itself; `bash`, `awk`, `jq`, `git` and util-linux's `flock`; and the
kit's side-by-side runner, which runs several at a time where GNU
parallel is installed, one at a time where it is not.
