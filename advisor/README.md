# advisor

A second, independent reading of one claim made about the code.

Nothing here sweeps, fixes, or runs on its own: it answers one claim at a
time, when one is brought to it. It reads the code rather than the
argument made about it. It changes nothing and commits nothing; what to
do with the answer stays with whoever asked.

It carries no context from the run that raised the claim, and sees the
proposal made about it only after giving its own answer.

Needs the laws a claim is raised under, to say whether what the code does
matters.
