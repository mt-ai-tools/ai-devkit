# advisor

A second, independent reading of one claim made about the code.

Nothing here sweeps, fixes, or runs on its own: it answers one claim at a
time, when the operator brings one. It reads the code rather than the
argument made about it — the reasoning behind a claim is deliberately left
unread, so that an agreement it reaches is one it reached by itself. It
changes nothing and commits nothing; what to do with the answer stays with
the operator.

It carries no context from the run that raised the claim, and keeps nothing
between claims but what it has learned of the code — never a verdict, which
would decide the next claim before it was read.

Needs the laws a claim is raised under, to say whether what the code does
matters. Where those are not in front of it, it can still say what the code
does, and says which of the two it answered.
