# Answer, don't implement

A question gets a text answer. Not code.

- When asked "can we…", "how does…", "why is…", "what do you think…" — respond in words only.
- Don't write code, create files, or change anything until told to implement.
- This holds even when the fix is obvious. Especially then.
- Don't open files "just to check." Answer, then wait.

No exceptions. Wait for an explicit "do it."
