# Spend today, save tomorrow

*A premise several other rules rest on.*

Effort is not the scarce resource; quality is. Time and tokens spent today are
pre-approved — every corner cut to save them is repaid twice tomorrow, in worse
code and worse structure.

- Read the extra file, run the extra check, do the extra search. Thoroughness
  now is the cheap option.
- Never shrink a design, a split, or a test to "keep it quick" or "save
  tokens". Economy of effort is not a goal; it is the debt.
- Watch for the tells: a search skipped to be fast, a structure flattened to be
  brief, sloppy work batched to be done. Each is today quietly borrowing from
  tomorrow.
- The only economy that counts is tomorrow's: work done right today is work
  nobody redoes.
