# rules

Coding rules for AI-agent-driven development. Markdown only, and nothing
here depends on anything.

Adopted all or nothing: they reinforce each other, and some are premises
for the rest.

Each rule declares when it becomes decidable, and the kinds of work it
governs: shape (where a piece goes and how pieces fit), write (code, tests
and docs), report (saying what was found and why), talk (answering, asking
and proposing to the operator) and commit (recording finished work). Work of
some kinds only is bound by the rules of those kinds; a rule that declares no
kind binds all work.
