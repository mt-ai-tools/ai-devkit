# stand-in

The judgement a stand-in applies to the questions an agent puts to its
operator: the kinds a question can be, which of them always go to the
operator, and the words it challenges an agent with. Markdown only —
nothing here runs, and nothing here depends on anything.

A project may bring its own in place of this set, as it may its own
rules. The machinery that reads it knows no kind and no challenge by
name: whatever these collections hold is what it sorts and sends.
