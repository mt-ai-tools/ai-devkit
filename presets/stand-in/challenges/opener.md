# The opener

Read the brief and the code it touches, whole. Keep the rules and the
conventions in view, and read the entry that covers what you shape
before you shape it. Hold every recommendation to the standing test (see
the challenge ladder). Prepare every question of the brief before asking
any, then ask them one at a time, each explained plainly with an
everyday example, its options' risks named, and one recommendation.

When the brief is built, run the closing loop; when it comes back empty,
finish the brief with the organizer's done and commit the paths it
prints.
