# Where a line belongs

- A line of prose — in a rule, shape, convention, README, comment or
  memory — earns its place only if missing it would let someone break
  something or undo a settled choice. It is short and factual.
- The home is set by how far the line holds, widest first: how an agent
  behaves, a rule; any project, a shape; this whole project, a
  convention; one block, its README; one piece of code, a why-comment
  beside it.
- An agent's memory holds only the operator's preferences and lessons
  met while working.
- A line that fits two homes goes in the wider one; the narrower one
  never repeats it.
