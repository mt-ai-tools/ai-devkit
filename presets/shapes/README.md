# shapes

Generic shapes of code and text for AI-agent-driven development: how
pieces are cut, placed, named, documented and tested. Markdown only, and
nothing here depends on anything. Project-free: a project's own choices
are its conventions, never a shape. How an agent behaves is not theirs:
the rules say it.

Each shape declares when it becomes decidable and the kinds of work it
governs, as the rules do, and binds work of those kinds as a rule does.
