# Plan

## Writing a draft
When: big work can wait (s2-route.md).
Do:
- The session writes it with the organizer's draft command, at a
  level the command takes, with the work as s1-intake.md records it.

## Writing a brief
When: the operator said yes to a brief and named its level.
Do:
- The session starts the brief-writer with everything the
  brief-writer's Starting section asks for.
- The brief-writer writes the brief in its own shape.
- The brief-writer decides every Silent and Told choice, marks
  every Advisor choice, and leaves every Operator choice open.
Don't:
- The brief-writer doesn't commit.

## Approving a brief
When: the brief-writer has reported.
Do, in this order:
1. The session has every Advisor choice in the brief decided as
   decisions.md says.
2. The session shows the operator each Told decision, laid out as
   decisions.md says.
3. The session asks the open Operator choices as s2-route.md
   says.
4. The session writes every answer into the brief, the advisor's
   with its reason, shows the operator each advisor decision laid
   out as decisions.md says, and commits the brief.
5. The operator says go. Building runs from there (s4-build.md);
   anything found along the way is sorted as s1-intake.md says.
Don't:
- No step is built before the go.

## Taking a draft as small work
When: a draft's trigger happens, or the operator wants a draft
  built, and the session finds it small.
Do, in this order:
1. The session takes the draft with the organizer's take command,
   so no other session starts it.
2. The session reads the draft against the code as it stands now,
   challenges it as s2-route.md says, and writes the fix down from
   what holds; a choice this raises is sorted as s1-intake.md says.
3. The session fixes it as small work (s2-route.md); where nothing
   is left to fix, it says why instead.
4. The session finishes the draft with the organizer's done
   command, and commits what it changed.

## A small draft proves bigger
When: building a draft taken as small work shows it is bigger.
Do:
- The session stops, frees the draft, and proposes a brief for it
  by "Turning a draft into a brief".

## Turning a draft into a brief
When: a draft's trigger happens, or the operator wants a
  draft built, and the session finds it bigger.
Do:
- The session proposes a brief for it to the operator, with a
  level.
- On yes, the draft becomes a brief by "Writing a brief", in the
  same file under the same name.
