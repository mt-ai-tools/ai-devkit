# Intake

## Recording new work
When: the operator, the session or a subagent has new work: an idea,
  a request or a finding.
Do:
- State what it is. For a finding, also where it is and how it is
  known.

## Findings from subagents
When: a subagent finds something outside its job.
Do:
- The subagent lists it in its report. Only a builder or fixer may
  fix a tiny one, in a file it already changes, as its own file says.

## Sorting new work
When: the session holds new work, its own, the operator's or a
  subagent's.
Do, in this order:
1. Blocks the current work: handle it first.
2. Holds choices for the operator (decisions.md): ask them, now or
   when the command in hand says.
3. Small: fix it now. Bigger: write it down.
4. Route it by s2-route.md.
