# Workflow

How work moves from a new idea to a closed brief, and who decides what
along the way. One file per stage, plus one board of who decides.

Each section opens with when it applies, then what to do, and, where it
adds a limit, what not to do.

## Terms

- Operator: the person who runs the work and makes the choices the
  board gives them.
- Session: the agent the operator talks to. It sorts the work, starts
  subagents and commits.
- Subagent: an agent the session starts for one job. It reports once
  and ends.
- New work: an idea, a request or a finding.
- Finding: something wrong, found in the code or in the work.
- Brief: big work written as steps, with its decisions. Nothing in it
  is built before the operator's go.
- Draft: big work written down to wait, until its trigger happens or
  the operator wants it built.
