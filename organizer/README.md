# organizer

Keeps the briefs and drafts, says which briefs are ready, waiting or
taken, and holds the one writer of a new brief.

The order of the work is derived, never kept: each brief's header says
what must land before it and where it works. How much a brief matters is
the level it lies in, and the organizer ranks nothing itself. A brief it
cannot vouch for is shown as a problem, never offered as work. Only a
ready brief can be taken. It is asked in plain words, through a skill.

A draft is big work that can wait. It lies only in the levels meant for
that, is never offered or taken, and is written through the organizer,
never by hand.

It changes only its own marks and the briefs and drafts a command names,
and prints every path it changed. It never runs version control. The
brief writer adds only the one new brief and the waits the operator's
yes named.

Needs a working folder of its own on this machine. What each level
means is held with its name in the kit. Needs nothing but `bash`, `awk` and `jq`.
